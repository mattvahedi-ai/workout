# workout

Troy workout log — a single-page, offline-friendly tracker (`index.html`) for the
4 lift + 2 cardio + 1 recovery Troy plan. Open it on your phone and "Add to Home Screen".

- **MON–SUN tabs** with the plan's exercises, prescriptions and starting weights
- **Progression targets**: shows when all sets hit the top of the rep range → add weight
- **Rest timer** (2:00 compound / 1:30 isolation)
- **Log workout** snapshots the day's numbers; each exercise shows your last logged session
- **PLAN tab**: this week's checklist, weekly progress tracker, training rules
- Data lives in browser localStorage; use EXPORT / IMPORT to back up
